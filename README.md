📄 Project Description
A lightweight Markdown to HTML converter built with JavaScript and regular expressions.
This app takes Markdown input from a textarea, parses it with regex rules, and outputs both the raw HTML code and a live rendered preview.

✨ Features
Converts headings (#, ##, ###) into <h1>, <h2>, <h3>

Supports bold (**text** or __text__) and italic (*text* or _text_)

Handles links [text](url) and images ![alt](src)

Converts blockquotes (> quote) into <blockquote>

Real‑time preview and raw HTML output side‑by‑side

🛠️ Tech Stack
HTML for structure

CSS for layout

JavaScript for logic and regex parsing
